# Employee Prediction Using Machine Learning

## Project Overview
This project uses Python and Machine Learning to analyze employee data and make predictions.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Google Colab

## Project Files
- Employee_Promotion_Prediction.ipynb – Python project notebook.
- aug_train.csv.zip – Dataset used for the project.

## Project Steps
1. Load the dataset.
2. Clean and preprocess data.
3. Perform exploratory data analysis.
4. Train machine learning models.
5. Evaluate model performance.
6. Generate predictions.

## Conclusion
This project provides practical experience in data analysis and machine learning.
